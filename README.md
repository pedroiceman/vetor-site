# Vetor Sistemas — Site institucional

Site institucional fictício de uma startup de tecnologia (desenvolvimento de
software e consultoria em inteligência artificial), desenvolvido como
atividade da disciplina de HTML5 e CSS3.

## Páginas

- `index.html` — Home
- `sobre.html` — Sobre Nós
- `servicos.html` — Serviços
- `cases.html` — Cases
- `contato.html` — Contato

## Tecnologias

- HTML5 semântico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 em arquivo externo (`style.css`), com variáveis, Flexbox e CSS Grid
- Design **mobile-first**, com media queries em 640px e 1024px
- Fontes web via Google Fonts (Space Grotesk + IBM Plex Sans), com unidades
  relativas (`rem`)
- JavaScript mínimo (`script.js`) apenas para o menu mobile

## Como visualizar

Basta abrir `index.html` em um navegador, ou publicar a pasta com o GitHub
Pages (Settings → Pages → branch `main` → pasta raiz).

## Estrutura de arquivos

